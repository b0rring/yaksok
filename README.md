# 약속(藥束)

어려운 처방 약을 쉬운 말로 풀어주고, 복약을 챙겨주는 노약자용 AI 복약 도우미 앱입니다. (프로토타입)

약 봉투를 사진으로 찍으면 AI가 약 이름, 먹는 법, 조심할 점을 큰 글씨의 쉬운 우리말로 정리하고, 알림과 캘린더에 자동으로 넣어 줍니다. 입력은 타이핑 대신 사진·녹음·버튼 한 번으로 끝나도록 만들었습니다.

## 무엇을 할 수 있나요

### 메인
- **홈**: 오늘 먹을 약을 아침·점심·저녁 카드로 보여주고, 탭 한 번으로 먹었다고 체크합니다. 먹은 횟수는 알약 게이지로 보이고, 아래에 주간 캘린더가 있습니다.
- **약 찍기**: 약 봉투나 처방전을 찍으면 AI가 읽고 정리합니다. 병명, 처방 병원, 약국, 조제일, 복용 시간대와 일수까지 함께 읽습니다. 오래 걸리는 작업은 화면을 붙잡지 않고 백그라운드에서 진행됩니다.
- **내 약**: 병명별로 약을 묶어 보여주고, 복용 기간 진행 상황, 약별 효능과 주의점, 같이 먹으면 안 되는 약을 확인합니다. 식약처 e약은요 공식 설명과 AI 설명을 구분해 표시합니다.
- **복약 알림**: 시간이 되면 어떤 병의 어떤 약을 먹을지 알림으로 알려 줍니다.
- **진료 기록**: 진료 내용을 녹음하면 받아쓰기와 요약이 오늘 날짜에 자동 저장됩니다. 의사에게 보여주기용 큰 글씨 화면도 있습니다.
- **AI 도우미**: 약에 대해 궁금한 것을 물어볼 수 있는 챗봇입니다.

### 사이드
- **병원·약국 찾기**: 지도에서 가까운 병원과 약국을 찾고, 전화와 길찾기로 이어집니다.
- **커뮤니티**: 환자와 의사가 글과 댓글로 소통합니다. 의사 답변에는 배지가 붙습니다.
- **계정·보호자 연동**: 보호자가 환자의 복약 기록을 함께 확인합니다.
- **설정**: 글씨 크기(보통·크게·아주 크게), 복용 시간 등.

> 이 앱의 설명은 참고용이며 진료를 대신하지 않습니다. 정확한 복용법은 의사나 약사에게 확인하세요.

# 개발 안내

## 기술 스택
- 앱: Expo(React Native, TypeScript, Expo Router), iPhone + Expo Go로 시연
- 서버: FastAPI, SQLite(계정·커뮤니티)
- AI: Google Gemini (사진 읽기, 녹음 정리, 챗봇), 식약처 e약은요, 카카오 지도

## 실행 방법
- 서버: `cd server && pip install -r requirements.txt && uvicorn main:app --host 0.0.0.0 --port 8000 --reload`
- 앱: `cd app && npm install && npx expo start` → 아이폰 Expo Go로 QR 스캔
- `app/.env`에 `EXPO_PUBLIC_API_URL=http://<PC 내부 IP>:8000` (아이폰에서 접속 시)
- 와이파이가 막혀 있으면 `npx expo start --tunnel`
- 키는 `server/.env`에 (`server/.env.example` 참고). 키가 없으면 mock 응답을 씁니다.

## 폴더 구조
- `app/` Expo 앱
- `server/` FastAPI 서버
- `PROJECT_STATUS.md` 현황 보고서(구현·확인 수준·변경 이력), `CLAUDE.md` 개발 지침, `기획서.md` 기획서
